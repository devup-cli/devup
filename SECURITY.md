# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in `devup` (such as command injection, unintended environment variable exposure in `devup doctor`, or path traversal):

1. **Do not** open a public GitHub issue.
2. Use GitHub's **Private Vulnerability Reporting** ("Security" tab -> "Report a vulnerability") on <https://github.com/devup-cli/devup/security/advisories/new>.
3. Include steps to reproduce, affected versions, and potential impact.

We will acknowledge reports within 72 hours and coordinate a fix and advisory before public disclosure.

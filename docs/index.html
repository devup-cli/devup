One command for every stack in your repo.

Zero-dependency Python CLI that auto-discovers scripts across package.json, pyproject.toml, pom.xml, build.gradle, Justfile, Makefile, and docker-compose.yml, then runs services in parallel with colored logs, HTTP/TCP readiness probes, .env loading, and clean Ctrl+C shutdown.

uvx --from devup-cli devup list pipx install devup-cli

5-Minute Getting Started

  1. Try without installing: uvx --from devup-cli devup list (or install globally via pipx install devup-cli).
  2. Discover tasks: Run devup list in any project directory to see scripts from Node, Python, Maven, Gradle, Make, Just, and Compose.
  3. Run in parallel: Run devup api web or use devup pick for an interactive arrow-key selector.
  4. Customize when needed: Run devup init to scaffold devup.toml with groups, depends_on, ready_url / ready_tcp, .env files, and watch rules.
  5. Validate & diagnose: Run devup validate and devup doctor to check configuration and installed runners.

CLI Command Reference

CommandDescription
devup list [--json]List all discovered groups and tasks across manifests.
devup run <targets...>Run tasks or groups concurrently with colored [service] prefixes (shorthand: devup a b).
devup pickInteractive arrow-key multi-select menu (numbered fallback in non-TTY).
devup init [--template ...]Create a starter devup.toml interactively or from a preset template.
devup validate [--json]Validate devup.toml syntax, dependencies, readiness URLs, paths, and ports.
devup doctor [--json] [--online]Inspect local runners offline and emit a redacted diagnostic report (scrubs paths, usernames, URL creds, and tokens).
devup completion <shell>Generate autocompletion scripts for bash, zsh, fish, or powershell.

Useful global flags: -C/--cwd, -w/--watch, --env-file, --no-dotenv, --strict-ports, --no-port-check, --keep-going, --dry-run, -t/--timestamps, --check-updates.

devup.toml Reference

default = ["dev"]
fail_fast = true
strict_ports = false
auto_env = true
env_file = [".env", ".env.local"]
shutdown_timeout = 5.0

[groups]
dev = ["db", "api", "web"]

[tasks.db]
command = "docker compose up postgres"
port = 5432
ready_tcp = "127.0.0.1:5432"
ready_timeout = 30

[tasks.api]
command = "uvicorn app.main:app --reload --port 8000"
cwd = "backend"
port = 8000
env_file = ".env.api"
depends_on = ["db"]
ready_url = "http://127.0.0.1:8000/health"
watch = ["app/**/*.py"]

[tasks.web]
command = "npm run dev"
cwd = "frontend"
port = 5173
depends_on = ["api"]

Troubleshooting & FAQ

How does devup avoid orphan processes on Windows and Unix?
Windows tasks are attached to kill-on-close Job Objects with Toolhelp32 descendant tracking and taskkill /F /T fallback; POSIX tasks run in their own process session and are swept via os.killpg.
Does devup install any third-party dependencies?
No. devup-cli runs strictly on the Python 3.11+ standard library.
Why is the PyPI package named devup-cli?
The bare devup name on PyPI was already taken by another package; installing devup-cli provides the devup command.
